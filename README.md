# Calc API

REST API калькулятор на Go. Принимает JSON с двумя числами и операцией, считает результат в отдельной горутине.

## Возможности

- HTTP-сервер на net/http
- Приём и отдача JSON
- Middleware для логирования запросов
- Вычисления в горутине через каналы и select
- Обработка ошибок (деление на ноль, неизвестная операция, плохой JSON)

## Стек

- Go 1.22+
- Стандартная библиотека (net/http, encoding/json)

## Запуск

go run .

Сервер запустится на http://localhost:8080.

## Пример запроса

curl -X POST http://localhost:8080/calc -H "Content-Type: application/json" -d "{\"a\":5,\"b\":3,\"op\":\"add\"}"

Ответ:

{"result":8}

## Операции

- add — сложение
- sub — вычитание
- mul — умножение
- div — деление
